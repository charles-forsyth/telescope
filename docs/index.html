Security & Architecture

Designed from the ground up for strict read-only compliance and secure credential isolation.

✓
OAuth 2.1 with PKCE (S256)

Standards-compliant authentication against Skywalker with dynamic client registration and loopback redirect.

✓
Native Keychain Isolation

Tokens live strictly in macOS Keychain or Windows Credential Manager. Never accessible to webview DOM.

✓
Two-Click Intent Gate

Sign-in requires two deliberate physical clicks. Prevents accidental authorization or focus clickjacking.

✓
100% Read-Only Guarantee

Telescope only issues query tool calls. It cannot create, alter, or delete any cloud resources.

✓
In-Memory Caching & Rate Limits

Strictly bounded concurrency (max 3 in-flight) and respectful HTTP 429 backoff with Retry-After honoring.

✓
Clean Revocation on Sign-Out

Revokes the refresh token on the Skywalker server (RFC 7009) and clears local secure storage.

Installation & Quickstart

Telescope is packaged as a universal macOS DMG (Apple Silicon & Intel).

1. Install DMG

Download Telescope-0.1.0-mac-universal.dmg from GitHub Releases and drag to Applications.

2. macOS Quarantine Override (if required)

If macOS warns about an unnotarized developer build, right-click and choose Open, or run:

xattr -dr com.apple.quarantine /Applications/Telescope.app

3. Building from Source

Requires Node.js 22+ and Rust stable:

git clone https://github.com/charles-forsyth/telescope.git && cd telescope
npm ci && npm test
cd src-tauri && cargo test && cd ..
npm run tauri build
